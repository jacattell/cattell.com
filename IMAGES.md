# Images still to add

The old Google Sites website would not let these 35 images be downloaded automatically.
Until a file is added, the website leaves that image out (it does not show a broken image).

To add one:

1. Open the page on the old website and save the image.
2. Rename it to the file name below.
3. Put it in `src/assets/img/`.

The files do not have to be JPEGs, but the name must match exactly, including `.jpg`.
Images are listed in the order they appear on each page.
Images marked "(no description)" also need alt text adding in the page's Markdown file.
