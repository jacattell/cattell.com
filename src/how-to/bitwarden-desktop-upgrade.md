---
title: "Bitwarden desktop upgrade"
---

1. Restart and **do not** load Bitwarden
2. [https://github.com/bitwarden/clients/tags](https://github.com/bitwarden/clients/tags)
3. Look for the latest desktop version
4. Click Downloads
5. Search for .rpm and download
6. Open Terminal
7. cd Downloads
8. sudo dnf upgrade ./Bitwarden-SOMETHING/\_64.rpm
9. Restart machine
10. Load Bitwarden
11. Check version is latest
