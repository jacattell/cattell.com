This statement is for www.cattell.com.

## What you should be able to do

You should be able to:

- zoom in up to 400% without text spilling off the screen
- use the whole website with just a keyboard
- use the website with a screen reader
- choose light or dark colours, or let your device choose
- read the words easily: I try to use plain English and short sentences

[AbilityNet](https://mcmw.abilitynet.org.uk/) has advice on making your device easier to use if you have a disability.

## How accessible this website is

I aim to meet the [Web Content Accessibility Guidelines (WCAG) version 2.2](https://www.w3.org/TR/WCAG22/) at level AA.

Every change to the website is checked automatically against these guidelines before it goes live. Automated checks find only some problems. If you find one they missed, please tell me.

## Things I know are not fully accessible

- Some older week notes and social media posts have pictures without a description.
- Some older week notes were written quickly and are not in plain English.
- The "Are you human?" check on the contact and feedback forms is run by Cloudflare. If it does not work for you, message me on [Bluesky](https://bsky.app/profile/jacattell.bsky.social), [Mastodon](https://mastodon.me.uk/@jacattell) or [LinkedIn](https://www.linkedin.com/in/jacattell/) instead.
- The "Ask my AI" page needs JavaScript.

## Tell me about a problem

If you find a problem, or need something in a different format, please [contact me](/contact/). I'll reply within 5 working days.

## Enforcement procedure

This is a personal website, so the [Public Sector Bodies Accessibility Regulations](https://www.legislation.gov.uk/uksi/2018/952/contents/made) do not apply to it. I follow them anyway, because it's the right thing to do.
